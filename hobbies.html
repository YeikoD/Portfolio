SAWebUI — Web UI Runtime for GTA San Andreas

Pionero en integrar una interfaz con tecnología web en GTA SA Singleplayer. Web UI runtime que renderiza HTML/CSS/JS dentro del juego usando CEF (Chromium Embedded Framework) en modo OSR. Expone una API pública para que cualquier mod pueda crear interfaces sin conocer CEF, D3D9 o Win32.

C++ JavaScript HTML/CSS CEF CLEO Redux
  • CEF OSR (Off-Screen Rendering) para renderizado en juego
  • API pública con 9 C exports y 7 CLEO commands
  • JS facade para mods CLEO Redux
  • Input y hit-testing integrados
  • Bridge RenderWare / D3D9 para integración con GTA SA
  • JS ↔ native messaging bidireccional
  • Multi-UI support para múltiples interfaces simultáneas
  • Cursor y keyboard focus management

Interactive PDA Reports

Interactive PDA Reports es un mod de inmersión para S.T.A.L.K.E.R. Anomaly que transforma la forma en que los personajes interactúan a través de la red PDA, creando un sistema de comunicación radiofónica dinámico y contextual.

📡 Concepto Principal

El mod hace que tu personaje y los NPCs se comuniquen vía radio a través de la red PDA cuando ocurren eventos importantes como el saqueo de cuerpos, creando una experiencia más inmersiva y social.

🎮 Mecánicas de Reporte

  • Reportes automáticos: Al saquear un cuerpo, tu personaje envía un mensaje a la PDA automáticamente
  • Texto contextual: El mensaje cambia según tu relación con el fallecido:
    • Amigo (≥400): Lamento por la pérdida de un aliado
    • Neutral (-400 a 400): Reporte genérico de muerte
    • Enemigo (≤-400, no lo mataste): Reporte de enemigo caído
    • Víctima (≤-400, lo mataste): Burla por el asesinato
  • Respuestas de NPCs: Si hay stalkers vivos de la misma facción, uno responde vía PDA
  • Comentarios externos: NPCs de otras facciones pueden comentar el evento

⚙️ Configuración (MCM)

  • Ego Factor: Probabilidad de reporte (100% = siempre, 0% = nunca)
  • Cooldown: Temporizador entre reportes para evitar spam
  • Recompensas: Pagos de Sidorovich por reportes
  • Demoras: Tiempo de espera para respuestas de NPCs

💰 Sistema de Recompensas

  • Pagos de Sidorovich vía PDA después de varios reportes
  • Configurable: cantidad por reporte, cuerpos por pago
  • Opción de excluir tus propias víctimas

💾 Persistencia

  • Contador de cuerpos y recompensas pendientes se guardan al salir
  • Se restauran al cargar, incluso entre cambios de nivel

🌍 Idiomas

  • Disponible en español e inglés
  • Detección automática del idioma del juego

📦 Instalación

  • Mod Organizer 2: Instalar el .zip o .7z vía "Install a new mod from an archive"
  • Manual: Extraer la carpeta gamedata en el directorio raíz de Anomaly
  • No sobrescribe archivos nativos del juego

Este mod no sobrescribe ningún archivo nativo del juego y es completamente compatible con otras modificaciones.

Grove Street Iron Syndicate

IronSyndicate es un mod ambicioso para GTA San Andreas que transforma el juego en una experiencia de gestión de imperio criminal. "No es solo un mod... es tu imperio."

📋 Información General

  • Versión: 1.0.0
  • Nombre: Grove Street Iron Syndicate
  • Permisos: Sistema de archivos (fs) y memoria (mem)
  • Tecnologías: JavaScript, HTML/CSS, CLEO Redux, ASI Plugin

🎮 Sistemas Principales

  • Portafolio Financiero: Gestión completa de activos, efectivo, propiedades, vehículos y mercancía en tránsito
  • Propiedades y Negocios: Sistema de alquileres, mantenimiento, negocios y lavado de dinero
  • Arsenal: Compra, venta, munición e inventario de armas
  • Flota: Gestión de vehículos, baúles, mantenimiento y combustible
  • Mercado Dinámico: Sistema de oferta, demanda, precios fluctuantes, proveedores y compradores

💰 Economía

  • Dinero Dual: Sistema de dinero limpio y sucio con mecánicas de lavado
  • Economía Dinámica: Precios que fluctúan según oferta y demanda
  • Riesgo y Reputación: Sistema de consecuencias por tus acciones criminales

🤖 NPCs y Diálogos

  • Sistema avanzado de NPCs con diálogos interactivos
  • Interacciones complejas con el mundo del juego
  • Misiones y eventos dinámicos

🎨 Interfaz

  • Interfaz web estilo GTA SA Stats Menu
  • Diseño responsivo y accesible
  • Integración perfecta con el gameplay original

Este mod está en desarrollo activo. Los sistemas mostrados en el concept art representan la visión completa del proyecto.
